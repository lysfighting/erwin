# Knowledge Skill

Codex-native skill for maintaining `erwin`'s knowledge system deliberately instead of letting docs sprawl happen by accident.

## Best Use

Use this when the model should:

- curate external signal into the right docs layer
- capture repeated Harness usage pressure as structured feedback
- write durable synthesis notes
- decide whether a knowledge thread deserves a proposal
- prune or demote stale research material

## Core Idea

`erwin` now treats knowledge as a layered system:

- `Radar` sees
- `Feedback` remembers real use
- `Knowledge` understands
- `Proposals` decide what may change

This skill is for the middle of that system, especially the `feedback -> knowledge -> proposals` seam.

## Install To Codex

```bash
./install-codex.sh knowledge
```
