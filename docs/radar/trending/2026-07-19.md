# GitHub Trending - 2026-07-19

Capture source: [GitHub Trending](https://github.com/trending)

## Trending Snapshot

The default global board captured on 2026-07-19 is mixed, but agent and coding-tooling projects are unusually prominent. It is not an AI-only board: desktop apps, terminal tooling, and general infra are still present. But several top repositories are directly about coding-agent context selection, browser/research surfaces, agent SDKs, observability, or computer-use infrastructure.

## Notable Projects

- [tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph)  
  Local-first code intelligence graph for MCP and CLI workflows, directly relevant to coding-agent context shaping and reviewability.

- [github/copilot-sdk](https://github.com/github/copilot-sdk)  
  Multi-platform SDK for integrating GitHub Copilot Agent into apps and services, notable because agent embedding is becoming a product surface of its own.

- [KnockOutEZ/wigolo](https://github.com/KnockOutEZ/wigolo)  
  Local-first search, fetch, crawl, and research for AI coding agents over MCP, one of the clearest coding-agent infrastructure entries on the board.

- [PostHog/posthog](https://github.com/PostHog/posthog)  
  Analytics, feature flags, experiments, and AI observability stack; still directly relevant to agent operations and feedback loops.

- [trycua/cua](https://github.com/trycua/cua)  
  Open infrastructure for computer-use drivers, cross-OS fleets, benchmarks, evals, and data generation.

- [1jehuang/jcode](https://github.com/1jehuang/jcode)  
  Explicitly positioned as a coding-agent harness, which makes it a useful signal that harnesses themselves are becoming legible open-source categories.

- [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch)  
  Practical AI engineering tutorial repo, showing continued demand for explicit foundations rather than only turnkey hosted products.

- [microsoft/terminal](https://github.com/microsoft/terminal)  
  A broad developer-tooling project that helps keep the board honest: the default global board is still a general developer board, not a curated agent list.

## Why They May Be Surfacing

- Coding-agent support infrastructure is consolidating. [tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph), [KnockOutEZ/wigolo](https://github.com/KnockOutEZ/wigolo), and [1jehuang/jcode](https://github.com/1jehuang/jcode) all point at the same pressure: better context selection, browsing, and harnessing around coding agents.
- Platform vendors are exposing agent-building surfaces directly. [github/copilot-sdk](https://github.com/github/copilot-sdk) surfacing on the default board suggests agent SDKs are now mainstream enough to trend without narrow filtering.
- Operator and eval layers remain part of the stack. [PostHog/posthog](https://github.com/PostHog/posthog) and [trycua/cua](https://github.com/trycua/cua) show that observability, experimentation, and computer-use benchmarking still matter alongside model quality.
- The board is still broadly representative. [microsoft/terminal](https://github.com/microsoft/terminal) and other non-AI projects remain visible, which helps separate real ecosystem heat from a forced AI-only reading.
