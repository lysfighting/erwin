# GitHub Trending Notes

`docs/radar/trending/` keeps one durable daily summary of the default GitHub Trending board.

## Rules

- file name format: `YYYY-MM-DD.md`
- use the default global GitHub Trending page without extra query filters
- update the current day's file in place rather than creating duplicates
- keep each note concise
- include direct repository links
- treat this as a popularity and momentum snapshot, not as first-party field direction
