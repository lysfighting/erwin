# GitHub Trending — 2026-04-02

Source board: [GitHub Trending](https://github.com/trending)

## Trending Snapshot

Today's default global board is unusually concentrated around Claude Code, coding-agent workflow, and developer-tooling repos, with a smaller mix of broader OSS utility projects still holding visible positions. The strongest cluster is agent orchestration and prompt/rules scaffolding, but the page is not AI-only: dashboard, terminal-presenter, shell-tooling, OSINT, JavaScript bundling, and certification/course-list repos are also surfacing.

## Why They May Be Surfacing

The safest read is clustering, not a single shared catalyst. Several repos are directly adjacent to Claude Code usage, agent orchestration, or AI coding workflow setup, so they likely benefit from the same active interest cycle. The non-AI projects look more like classic Trending behavior: polished utilities, broadly useful developer infrastructure, and high-share educational resources that are easy to adopt quickly.

## Watchlist

- Watch whether Claude Code adjacency remains dominant tomorrow or if this was a short-lived burst around workflow tooling.
- Track whether rule packs, orchestration wrappers, and agent-demo repos keep outranking deeper infrastructure.
- Keep an eye on non-AI breakouts like [rolldown/rolldown](https://github.com/rolldown/rolldown), [glanceapp/glance](https://github.com/glanceapp/glance), and [mfontanini/presenterm](https://github.com/mfontanini/presenterm); if they persist, the board is broader than today's top cluster suggests.
