# GitHub Trending - 2026-07-28

Capture source: [GitHub Trending](https://github.com/trending)

## Trending Snapshot

The default global board captured on 2026-07-28 is broad rather than AI-dominated. Architecture tooling, CI infrastructure, terminal UX, voice/agent projects, geospatial software, and finance-curation repos are all present together. AI and agent projects are clearly on the board, but they are competing with general developer and systems repos instead of defining the whole page.

## Notable Projects

- [pascalorg/editor](https://github.com/pascalorg/editor)  
  3D architectural project editor; notable because a specialized builder tool is leading a default global board.

- [jenkinsci/jenkins](https://github.com/jenkinsci/jenkins)  
  Classic automation server; included because the board is not purely novelty-driven and still surfaces durable infra anchors.

- [moeru-ai/airi](https://github.com/moeru-ai/airi)  
  Self-hosted AI companion and realtime agent shell; one of the clearest agent-native projects on the board.

- [andrewyng/aisuite](https://github.com/andrewyng/aisuite)  
  Unified interface to multiple generative AI providers; relevant because provider fragmentation remains a live development problem.

- [huggingface/speech-to-speech](https://github.com/huggingface/speech-to-speech)  
  Local voice-agent stack; notable because practical multimodal agent building remains attractive.

- [microsoft/agent-governance-toolkit](https://github.com/microsoft/agent-governance-toolkit)  
  Governance toolkit for AI agents; relevant because policy, sandboxing, and reliability are now mainstream concerns.

- [yorukot/superfile](https://github.com/yorukot/superfile)  
  Modern terminal file manager; included because non-AI developer ergonomics remain strong on the default board.

- [bradautomates/claude-video](https://github.com/bradautomates/claude-video)  
  Video-to-Claude evidence pipeline; relevant because richer input preparation for agents continues to surface.

## Why They May Be Surfacing

- Specialized creation tools are getting attention beyond the usual web-stack defaults. [pascalorg/editor](https://github.com/pascalorg/editor) is the clearest example.
- Infra and workflow anchors still matter. [jenkinsci/jenkins](https://github.com/jenkinsci/jenkins) surfacing suggests the board is not only chasing new AI repos.
- Multi-provider and governance layers remain practical AI pain points. [andrewyng/aisuite](https://github.com/andrewyng/aisuite) and [microsoft/agent-governance-toolkit](https://github.com/microsoft/agent-governance-toolkit) fit that pattern directly.
- Richer agent interaction modes keep pulling interest. [moeru-ai/airi](https://github.com/moeru-ai/airi), [huggingface/speech-to-speech](https://github.com/huggingface/speech-to-speech), and [bradautomates/claude-video](https://github.com/bradautomates/claude-video) point to voice, realtime, and multimodal evidence as active demand areas.
- General developer UX still competes well with AI projects. [yorukot/superfile](https://github.com/yorukot/superfile) is a straightforward example.
