# GitHub Trending - 2026-07-02

Capture source: [GitHub Trending](https://github.com/trending)

## Trending Snapshot

The default global board captured on 2026-07-02 is still mixed rather than AI-only, but AI/security/devtool projects are unusually prominent. The surface currently blends agent security tooling, trading agents, document/OCR infrastructure, frontend systems, learning repos, and a few sponsor-style tiles. The broad takeaway is that packaged workflows and operational tools are still beating abstract framework claims.

## Notable Projects

- [usestrix/strix](https://github.com/usestrix/strix)  
  Open-source AI penetration-testing tool positioned around finding and fixing application vulnerabilities.

- [HKUDS/Vibe-Trading](https://github.com/HKUDS/Vibe-Trading)  
  A personal trading-agent project, notable because it frames the repo as an operational agent rather than a model wrapper.

- [facebook/astryx](https://github.com/facebook/astryx)  
  An open-source design system explicitly described as customizable and agent ready, which is an interesting sign that agent pressure is reaching design-system infrastructure.

- [allenai/olmocr](https://github.com/allenai/olmocr)  
  OCR/linearization tooling for turning PDFs into LLM-usable text, still a core ingestion problem for agent workflows.

- [Unclecheng-li/VulnClaw](https://github.com/Unclecheng-li/VulnClaw)  
  AI agent + MCP + pentest skill-chain orchestration, relevant as a more explicitly chained security-agent workflow.

- [microsoft/AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners)  
  A durable teaching repo rather than a frontier release, but its resurfacing usually signals active new builder demand.

## Why They May Be Surfacing

- Security remains one of the clearest "agents do real work" narratives. Both `strix` and `VulnClaw` sell end-to-end security outcomes, not just chat UX.
- Workflow packaging is winning. Repos that bundle a complete lane such as trading, OCR ingestion, or agent-ready UI systems are surfacing more than generic abstractions.
- The board is still a useful check against overfitting to model vendors alone. A repo like `olmocr` matters because agent systems still depend on document ingestion quality.
- AI momentum on the board is bleeding into adjacent layers like design systems and education, not just core model or benchmark repos.
