## Trending Snapshot

The default board still is not narrowly AI-only, but AI-adjacent developer tooling, browser automation, agent runtime infrastructure, and technical education remain highly visible. The mix still looks more like "builders' infrastructure week" than a consumer-app wave.

## Why They May Be Surfacing

- Agent runtime infrastructure is still hot. [UI-TARS-desktop](https://github.com/bytedance/UI-TARS-desktop), [hermes-agent](https://github.com/NousResearch/hermes-agent), and [agentmemory](https://github.com/rohitg00/agentmemory) all fit the broader shift toward durable multi-step systems instead of single-turn assistants.
- Browser control remains a contested foundation layer. [CloakBrowser](https://github.com/CloakHQ/CloakBrowser) is surfacing because browser execution that survives hostile environments is strategically important for both agents and automation.
- Verification and cleanup tooling for AI-authored code is surfacing as its own category. [react-doctor](https://github.com/millionco/react-doctor) is notable because it assumes AI coding output needs specialized review gates.
- The board is still broader than pure AI. [supersplat](https://github.com/playcanvas/supersplat) and [LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch) show that graphics tooling and educational repositories can still rise alongside agent infrastructure on the default global board.
