## Why They May Be Surfacing

- Skill-centric agent workflows are hot. [superpowers](https://github.com/obra/superpowers), [scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills), [skills](https://github.com/mattpocock/skills), and [gstack](https://github.com/garrytan/gstack) all assume reusable operational patterns matter as much as base models.
- Durable execution state remains a live need. [agentmemory](https://github.com/rohitg00/agentmemory) is surfacing because persistent state is still a hard problem for coding agents and autonomous loops.
- Browser and infrastructure control remain foundational. [CloakBrowser](https://github.com/CloakHQ/CloakBrowser) and [telegraf](https://github.com/influxdata/telegraf) point to runtime control, observability, and hostile-environment execution as shared concerns.
- The board is broader than AI. [RuView](https://github.com/ruvnet/RuView) and [supervision](https://github.com/roboflow/supervision) show that sensing, vision, and systems tooling still compete effectively for attention on the default global page.
