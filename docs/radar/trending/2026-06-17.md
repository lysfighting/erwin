# GitHub Trending - 2026-06-17

Capture source: [GitHub Trending](https://github.com/trending)

## Trending Snapshot

The default global board captured on 2026-06-17 is broad and practical rather than narrowly AI-branded. Self-hosted systems, browser tooling, developer education, media/community infrastructure, and a smaller set of AI and infra repos are all present together. The right reading is "general build-and-operate demand with a visible agent/tooling slice," not "the board has turned into an AI leaderboard."

## Notable Projects

- [freeCodeCamp/freeCodeCamp](https://github.com/freeCodeCamp/freeCodeCamp)  
  Open-source curriculum and learning platform; still one of the clearest broad developer-demand indicators on the board.

- [iptv-org/iptv](https://github.com/iptv-org/iptv)  
  Large public IPTV index; a reminder that the default global board still includes mass-interest utility repositories.

- [teslamate-org/teslamate](https://github.com/teslamate-org/teslamate)  
  Self-hosted Tesla data logger; useful signal for durable operator and self-hosting demand.

- [puppeteer/puppeteer](https://github.com/puppeteer/puppeteer)  
  Browser automation API for Chrome and Firefox; highly relevant to web-acting agents and reproducible browser execution.

- [meshery/meshery](https://github.com/meshery/meshery)  
  Cloud-native manager; important because control-plane and observability UX still travel with every serious distributed system.

- [music-assistant/server](https://github.com/music-assistant/server)  
  Self-hosted media library manager; another sign that home-lab and operator-friendly infrastructure remain a strong open-source demand category.

- [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM)  
  Multilingual speech generation and voice cloning model stack; the clearest direct AI-model entry on this board snapshot.

- [alibaba/zvec](https://github.com/alibaba/zvec)  
  Lightweight in-process vector database; relevant for retrieval-heavy applications and local inference stacks.

- [n0-computer/iroh](https://github.com/n0-computer/iroh)  
  Modular Rust networking stack; notable because transport and connectivity layers are increasingly coupled to distributed agent execution stories.

## Why They May Be Surfacing

- The board continues to reward practical software people can run, host, or integrate today, not only frontier-model launches.
- AI-adjacent repos that surfaced are mostly infrastructure-shaped: browser control, voice models, vector storage, and network substrate.
- Self-hosted operator tools remain prominent, which fits the broader trend that developers want systems they can inspect and control locally.
- Education still holds a visible slot on the board, so the ecosystem is still absorbing and operationalizing the last wave of AI/dev-tool change rather than moving on from it.
