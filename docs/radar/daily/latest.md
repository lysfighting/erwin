# AI Agent Daily Radar - 2026-04-20

Window: 2026-04-14 to 2026-04-20

## New Signals

- **Anthropic moved its agent platform forward with Opus 4.7 and Claude Code runtime changes.** Anthropic's [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) list **April 16, 2026** for Claude Opus 4.7, positioning it for complex reasoning and agentic coding, plus same-window Bedrock availability and **April 14, 2026** deprecation pressure for older Claude 4 models. The official [Claude Code changelog](https://code.claude.com/docs/en/changelog) then shows Opus 4.7 support and runtime hardening across **April 16-18, 2026**, including `xhigh` effort, native binary spawning, network deny-list controls, stalled-subagent failure surfacing, MCP timeout fixes, and security tightening around Bash permissions. Collapsed takeaway: Anthropic is combining stronger model upgrades with sharper agent-runtime policy, observability, and failure behavior.
- **Claude Managed Agents and the advisor tool remain the key Anthropic platform betas to track.** The required Anthropic surface check found no newer dated doc than the platform notes: [Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview) remains the **April 8, 2026** public beta for a managed autonomous-agent harness with sandboxing, built-in tools, and SSE streaming; the [advisor tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool) remains the **April 9, 2026** public beta for pairing a faster executor model with a higher-intelligence advisor model. These are not new today, but they remain in-window and directly shape harness planning/execution separation.
- **OpenAI made Codex and the Agents SDK more explicitly harness-native.** OpenAI published [The next evolution of the Agents SDK](https://openai.com/index/the-next-evolution-of-the-agents-sdk/) on **April 15, 2026**, adding a model-native harness, native sandbox execution, portable workspace manifests, filesystem/shell/apply-patch tools, MCP, skills, memory, snapshotting, and rehydration. OpenAI then published [Codex for (almost) everything](https://openai.com/index/codex-for-almost-everything/) on **April 16, 2026**, adding desktop computer use, an in-app browser, expanded plugins, SSH/devbox support, memory preview, and automations that can reuse existing conversation threads. Collapsed takeaway: OpenAI is pushing the same agent loop into both SDK infrastructure and end-user developer workflow.
- **Google made Gemini CLI subagents first-class.** Google published [Subagents have arrived in Gemini CLI](https://developers.googleblog.com/subagents-have-arrived-in-gemini-cli/) on **April 15, 2026**. Subagents run in isolated context windows with their own instructions, curated tools, MCP servers, Markdown definitions, `@agent` invocation, `/agents` visibility, and parallel execution. Google's explicit warning about parallel edit conflicts matters for Harness: delegation needs ownership boundaries, merge policy, and usage-limit awareness, not just more workers.
- **Qwen and Moonshot show open coding-agent pressure around hooks, memory, recovery, and long turns.** Qwen's [qwen-code v0.14.5](https://github.com/QwenLM/qwen-code/releases) shipped on **April 15, 2026** with fork-subagent support, non-interactive context usage data, streamed rate-limit detection, Gemini thought-only response handling, and OAuth-free-tier cutoff behavior; Qwen also noted [Qwen3.6-35B-A3B availability](https://github.com/QwenLM/Qwen3.6) on **April 16, 2026**. Moonshot's [Kimi Code CLI changelog](https://moonshotai.github.io/kimi-cli/en/release-notes/changelog.html) shows **1.36.0 on April 17, 2026**, fixing Claude Opus 4.7 compatibility and raising default `max_steps_per_turn` from 100 to 500 after April 13-15 recovery and MCP-output fixes. Collapsed takeaway: open agent CLIs are optimizing for longer uninterrupted runs, provider compatibility, recovery, hooks, memory, and context control.

## Harness-Relevant Signals

- First-party providers are converging on a shared harness vocabulary: sandbox/container, workspace manifest, filesystem tools, shell/apply-patch tools, MCP, skills, memory, tracing, resumability, subagents, and policy-controlled execution.
- Anthropic's advisor tool and OpenAI's Agents SDK both separate strategy from execution. Harness should treat planner/executor/advisor splits as an eval surface before locking in any permanent product shape.
- Claude Code, Gemini CLI, Qwen Code, and Kimi Code all show pressure around long-running sessions: stalled subagents, stream recovery, rate-limit detection, provider-specific thinking formats, recap/memory, hooks, and safe shell permissions.
- Subagent ecosystems are now explicit enough that ownership boundaries matter more than raw parallelism. The recurring risk is agents colliding on edits, silently losing state, or summarizing away necessary evidence.
- MiniMax and DeepSeek produced no stronger April 14-20 first-party technical agent-runtime item than the signals above. MiniMax's in-window official items were event recaps and terms updates; DeepSeek's official API changelog still shows its latest model/API entry as **2025-12-01**, while its homepage currently advertises DeepSeek-V3.2 as agent-oriented without a new April-dated technical note.
