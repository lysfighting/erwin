# AI Agent Daily Radar — 2026-04-08

Window: 2026-04-01 to 2026-04-08

## New Signals

- **OpenAI is separating coding-agent runtime from ordinary chat seats.** OpenAI's help article [Managing members, seat types, roles and access in ChatGPT Enterprise](https://help.openai.com/en/articles/8266401-managing-members-seat-types-roles-and-access-in-chatgpt-enterprise) was updated on **April 2, 2026** to add `Codex` seat types and a token-priced `Codex Rate Card`. The important signal is operational, not cosmetic: OpenAI is treating agent execution as its own governed budget and access surface.
- **Google is pushing agentic coding down the cost curve inside the terminal.** In [Gemini 3 Flash is now available in Gemini CLI](https://developers.googleblog.com/gemini-3-flash-is-now-available-in-gemini-cli/) on **April 7, 2026**, Google positioned Gemini 3 Flash as the low-latency default for high-frequency coding work, with large-context PR handling, load-test generation, and stronger agentic coding performance inside Gemini CLI.
- **Google is also making on-device agent workflows concrete instead of aspirational.** In [Bring state-of-the-art agentic skills to the edge with Gemma 4](https://developers.googleblog.com/bring-state-of-the-art-agentic-skills-to-the-edge-with-gemma-4/) on **April 2, 2026**, Google tied Gemma 4 to `Agent Skills` in Google AI Edge Gallery and `LiteRT-LM`, framing multi-step planning, tool-like skills, constrained decoding, and edge deployment as one usable developer path.
- **DeepSeek's official status surface still reads as a reliability warning for long-running agents.** DeepSeek logged [Web/API service unavailable](https://status.deepseek.com/incidents/5d7vfs0fxnkl) on **April 3, 2026**. This is not a model launch, but it is a first-party operational signal that reinforces why multi-provider agent systems need health-aware routing, retries, and graceful degradation.
