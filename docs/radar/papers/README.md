# Paper Watch

`docs/radar/papers/` is the durable paper-watch archive for the `erwin` radar.

This directory exists because paper and benchmark intake should be visible and reviewable without being merged into the main daily radar stream.

Its job is to hold selective, slower-moving notes about:

- agent methods
- coding-agent benchmarks
- self-improvement and self-correction work
- orchestration and observability papers that materially sharpen active knowledge threads

## Working Rules

- do not mirror every interesting paper
- prefer grouped watch notes over one file per paper
- connect each note to at least one active knowledge thread
- route durable implications into `docs/knowledge/` before opening or widening proposals
- keep benchmark and paper watch slower and more selective than first-party field radar
