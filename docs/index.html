The official Claude Code changelog lists version 2.1.108 on April 14, 2026, adding 1-hour prompt-cache TTL controls, session recap, slash-command discovery through the Skill tool, better resume defaults, sharper rate-limit errors, and fixes for Agent-tool permission handling and transcript durability. This is the clearest Claude Code in-window signal: coding-agent reliability is moving into cache policy, resumability, hooks, monitors, worktrees, and remote/headless execution.
  • Anthropic added a platform migration clock for older Claude 4 models. The Claude Platform release notes dated April 14, 2026 announce deprecation of claude-sonnet-4-20250514 and claude-opus-4-20250514, with API retirement scheduled for June 15, 2026, and recommend migration to Claude Sonnet 4.6 and Claude Opus 4.6. For harness work, this is less a feature launch than a dependency hygiene signal: long-running agent systems need explicit model-lifecycle checks, migration tests, and stale-model detection.
  • Anthropic's Managed Agents public beta remains the strongest managed-runtime signal in-window. The Claude Platform release notes date the launch to April 8, 2026, and the Managed Agents overview describes a pre-built configurable agent harness for long-running and asynchronous work, with agents, environments, sessions, events, built-in tools, MCP, skills, server-sent event streaming, and beta access via managed-agents-2026-04-01. The paired Anthropic engineering post, Scaling Managed Agents: Decoupling the brain from the hands, makes the architecture explicit: session log, harness, and sandbox are separated so each can fail or evolve independently.
