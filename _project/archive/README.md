# _project/archive

This directory holds project-history material that should remain available without dominating daily navigation.

## Included

- `sessions/` — curated AI session logs that are still referenced by the live repo surface

## Compatibility

The repository keeps `_project/sessions` as a compatibility symlink into this archive so old links and skills continue to work while the repo surface is being simplified.

## Working Rule

Use `_project/CURRENT.md` and `_project/GOALS.md` as the live entrypoints.
Treat archived session logs as supporting evidence, not the default start point.
If a session log is no longer referenced by the active repo surface, it is a deletion candidate rather than a permanent archive asset.
