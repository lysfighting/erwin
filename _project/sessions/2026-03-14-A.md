#### 🔮 Claude

*（开了 claude-code-guide agent + WebSearch + WebFetch 拉取官方文档）*

**核心发现：我们的写法从根本上就不符合官方架构。**

| 维度 | 官方推荐 | teamwork 现状 |
|------|---------|--------------|
| SKILL.md 大小 | **≤500 行** | **4,594 行**（9.2x 超标） |
| 复杂内容 | supporting files 按需加载 | 全部塞进一个 .md |
| 重操作 | `context: fork` 或 custom agent | 同一个 context 执行 |
| 文件结构 | SKILL.md + reference/ + templates/ + scripts/ | 单个巨型 .md + scripts/ |

三个关键机制（一个都没用）：
1. **Supporting Files** — SKILL.md 引用，Claude 按需 Read
2. **`context: fork`** — 在隔离 subagent 里运行
3. **Custom Agents (.claude/agents/)** — 预加载特定 skill

**`${CLAUDE_SKILL_DIR}` 变量**可引用子文件路径。

**必须从 `.claude/commands/` 迁移到 `.claude/skills/`** 才能用目录结构。

Self-rebuttal 翻转：之前担心 "Read 延迟" — 但这就是 Anthropic 设计的使用方式，不是 hack。
