Phase Ω 本质洞察：vi_agent 需要 staging + prod 环境，核心问题是 IaC 边界划在哪 + CD pipeline 怎么接。

IaC 归属判断 — **Hybrid 方案是唯一合理选择**：

| 维度 | gcp-compute-infra | vi_agent |
|------|-------------------|----------|
| 管什么 | 机器（VM/磁盘/网络/SSH） | 应用（容器/配置/端口/SSL） |
| 变更频率 | 月级 | 日级 |
| 跨项目 | 是（agentone, nginx） | 否 |

为什么不纯 A：Deploy 和 app 强耦合。为什么不纯 B：Terraform 管全公司机器，放 vi_agent 是越界。

Mission Contract:
- gcp-compute-infra: staging + prod VM Terraform
- vi_agent: deploy.yml workflow（staging 自动 + prod 手动）+ docker-compose
- /team-release staging gate 修复
