## Bugs Found During E2E

### Bug 1: tw-config.sh inline comment not stripped

**Symptom**: `tw-config.sh github.mc_label "mission"` returned `mission-contract"  # label that identifies Mission Contracts` instead of `mission-contract`.

**Root cause**: The Python3 parser did `.strip().strip('"').strip("'")` — worked for clean values, but YAML inline comments after closing quote (`"value"  # comment`) prevented `strip('"')` from removing the trailing quote (string ended in `s`, not `"`).

**Fix**: Added `strip_val()` helper. For quoted values: find first matching quote pair, extract content. For unquoted: split on ` #` marker before stripping.

### Bug 2: mc_label schema mismatch

**Symptom**: Skills called `tw-config.sh mc_label "mission"` but vi_agent has `github.mc_label: "mission-contract"` — nested under `github:` section.

**Root cause**: Skills were written for erwin's flat config schema where `mc_label` is top-level. vi_agent uses `github:` wrapper section.

**Fix**: Skills now try `github.mc_label` (teamspace schema) first, then `mc_label` (teamwork schema), then fall back to `"mission"`. Both schemas supported.
