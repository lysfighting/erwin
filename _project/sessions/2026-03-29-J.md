# Session Log — 2026-03-29 J

## Summary

Extended the harness ownership model from exact-match `kind:value` selectors into a richer selector-family baseline with semantic overlap detection.

## What Changed

- Ownership selector parsing now normalizes selector aliases:
  - `directory:` / `folder:` -> `dir:`
  - `path:` -> `file:`
  - `component:` -> `module:`
- Ownership selectors now carry richer metadata:
  - `family`
  - `match`
  - `bounded`
- Path-family selectors now have semantic overlap behavior:
  - `file` vs `file` => exact overlap
  - `file` vs `dir/module` => file-inside-prefix overlap
  - `dir/module` vs `dir/module` => prefix overlap in either direction
- Ownership transfer now rejects all non-bounded selectors generically instead of only hardcoding `mission:` / `branch:`.
- Overlap admission checks now use selector semantics, not just raw string equality.
- `home` and `doctor` ownership-overlap reporting now detect semantic overlap, not only identical claims.
- Teammate smoke now verifies a real semantic conflict:
  - one run owns `dir:docs/release`
  - another run tries to own `file:docs/release/CHANGELOG.md`
  - the assignment is correctly rejected
- The teammate smoke helper was also hardened to avoid `pipefail` false negatives on large JSON payloads.
