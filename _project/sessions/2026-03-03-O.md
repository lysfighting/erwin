## Key Decisions

- **tw-config.sh is Python3, not bash** — no external deps (PyYAML not installed), simple line-by-line YAML parser covers our schema subset. bash approach would require more complex sed/awk.
- **Bidirectional sync is non-fatal** — mission must not block on GitHub API failures; Issue body format may not always match exactly. Warn + continue.
- **Version from Milestone, not config** — `versions.current` in config is legacy; Issue's `milestone.title` is the authoritative source. Config is fallback for compatibility.
- **REPO from `gh repo view`** — team-issue had `grep 'repo:'` which doesn't match standard config schema. `gh repo view` auto-detects correctly.
