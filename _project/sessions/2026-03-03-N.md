## Completed

### Mission 1: Fix `/team-ship` status lifecycle (v2.3.1)

**Root cause**: LLM outputs `✅` from template text regardless of whether `gh issue edit` succeeded. Dashboard had no REVIEW section.

**Changes**:

### Mission 2: Version management + issue format standardization (v2.3.2)

**Root cause**: `versions.current` in config was never wired to actual GitHub Milestones. Format divergence between `team-issue.md` output and `mission.yml` GitHub template.

**Changes**:
- `team-issue.md`: Extract `CURRENT_VERSION` from config → assign `--milestone` on `gh issue create`. Add `### Objective` section (was missing). Canonical field names: `Success Criteria`, `Context & References`.
- `team-claim.md`: Parse both `Success Criteria` (canonical) and `Acceptance Criteria` (legacy). Populate `version:` frontmatter from config.
- `team.md`: Un-comment version progress; use GitHub Milestones API (`gh api repos/{REPO}/milestones`), not custom version labels.

**Key insight**: `versions.current` → GitHub Milestone (not custom label). GitHub has first-class support for this.

### Mission 3: Script-based skill architecture pilot (v2.3.3)

**Root cause**: All 5 skill .md files have the same ~20-line config parsing boilerplate that the LLM must interpret. Label creation is a 10-command sequence the LLM interprets unreliably.

**Changes**:
- `skills/teamwork/scripts/setup-github-labels.sh`: Executable bash script, reads prefixes from config, `--force` for idempotency. The script that was already REFERENCED in error messages but didn't exist.
- `install.sh`: `install_skill()` now checks for `scripts/*.sh` and symlinks/copies to `$TARGET_DIR/scripts/`.
- `team.md` Step 5a: Calls script first, falls back to inline commands.

**Pattern established**: skill folder = `.md` (AI reasoning brain) + `scripts/` (deterministic bash operations). LLM runs scripts; scripts handle the mechanical work.

## Key Decisions

- **Version → Milestone (not label)**: GitHub Milestones is the right primitive for version grouping. Custom labels duplicate existing functionality.
- **Scripts = programs, not environment setters**: Bash tool calls are stateless (no `source` across calls). Scripts must be self-contained programs that DO things, not set variables.
- **Template text decoupled from reality**: The core pattern bug — LLM outputs assumed success strings from templates. Fix: always fetch actual state from GitHub after mutations.
