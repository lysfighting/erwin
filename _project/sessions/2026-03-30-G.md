# Session Log — 2026-03-30 G

## Summary

- Added explicit bundle-governor adoption and retirement to the mission control plane.
- Taught mission-graph authority and scheduler to consume that explicit governor instead of treating escalation-required bundles as permanently unresolved.
- Proved the full adoption and clear path in core smoke.

## Why

`Harness` could already detect escalation-required mission bundles, rank plausible governors, and surface one bundle-scoped `establish_bundle_governor` decision packet. But the leader still lacked a deterministic way to adopt that decision inside the runtime itself. The next control-plane step was to let the leader convert an unresolved bundle into governed authority explicitly, then retire that governance cleanly when it no longer applied.

## What Changed

- `internal/harness/runtime.go`
  - added explicit-governor signal helpers so mission-graph authority can consume active `bundle_governor_established` signals
  - `missions authority-audit --all` can now emit `resolution_kind: "explicit_bundle_governor"` when a leader-adopted bundle governor is present
  - added `missions establish-governor BUNDLE_ID GOVERNING_MISSION_ID [NOTE]`
  - added `missions clear-governor BUNDLE_ID [NOTE]`
  - scheduler now treats explicitly governed bundles as governed authority instead of repeatedly surfacing `establish_bundle_governor`
- `scripts/harness-smoke-test.sh`
  - added explicit-governor coverage proving a bundle moves from `bundle_governor_required` to `explicit_bundle_governor`
  - verified scheduler stops repeating the establish-governor decision while the explicit governor is active
  - verified clearing the explicit governor returns the bundle to the unresolved governor-required state

The leader can now close the loop on bundle-governor decisions inside the control plane itself. Escalation-required mission bundles are no longer stuck as permanent recommendations; they can be explicitly governed, consumed by authority audit and scheduler logic, and later released back into unresolved bundle state when needed.
