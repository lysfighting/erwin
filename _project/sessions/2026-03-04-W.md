## Key Bugs Fixed

### CRITICAL
1. **tw-git.sh cmd_tag**: `git rev-parse "$version"` matched branches → `refs/tags/$version`
2. **tw-git.sh cmd_merge_to**: `checkout && pull` chain — checkout fail → merge on wrong branch → explicit `|| exit 2`

### HIGH
3. **tw-git.sh cmd_ensure_base**: silent failure on checkout → explicit error
4. **tw-git.sh cmd_create_branch**: sed metachar injection → bash `${//}` expansion
5. **tw-git.sh cmd_rebase/merge_to**: `fetch 2>/dev/null` with `set -e` → `|| WARNING`
6. **tw-git.sh cmd_tag**: grep `.` = any char → `grep -qF` fixed string
7. **tw-pr.sh cmd_commit_type**: "prefix"→fix false positive → `grep -qEw` word boundary
8. **tw-contract.sh cmd_toggle_task**: false success on N > count → `found` flag + exit 1

### Pattern: `set -euo pipefail` + `&&` chains
The single biggest bug class. `set -e` does NOT trigger on failed commands in `&&`/`||` chains. 3 of 8 CRITICAL/HIGH bugs were this pattern. Fix: always use explicit `|| { error; exit; }`.
