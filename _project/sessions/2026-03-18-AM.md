## Technical Lessons

1. **`set -e` + `((PASS++))` bug**: When counter starts at 0, `((0++))` returns exit 1 → kills script under `set -e`. Fix: use `PASS=$((PASS + 1))` instead of `((PASS++))`.

2. **install.sh `--target` for modern skills**: Initial implementation ignored `--target` for modern skills (always wrote to `~/.claude/skills/`). Fixed by deriving `SKILLS_TARGET_DIR` from `TARGET_DIR`.

3. **Operations extraction strategy**: Keep cognitive micro-languages in SKILL.md, extract heavy discrete operations. The SKILL.md is what loads into context on every invocation — keep it lean. Operations load on-demand.
