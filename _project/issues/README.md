# Issues

Lightweight issue tracking for bugs, features, and tasks.

## Naming Convention

`ISS-NNNN-short-title.md`

## Status Values

- `Open` — not started
- `In Progress` — being worked on (link to session)
- `Done` — completed (link to commit/release)
- `Won't Fix` — decided not to address (explain why)

## Priority Values

- `P0` — blocking, fix immediately
- `P1` — important, do this week
- `P2` — backlog, when time permits

## Types

- `Bug` — something broken
- `Feature` — new capability
- `Task` — maintenance, refactor, docs
- `Research` — investigation needed

## Template

```markdown
# ISS-NNNN: Title

- **Date**: YYYY-MM-DD
- **Status**: Open
- **Type**: Feature
- **Priority**: P1
- **Session**: [YYYY-MM-DD](../sessions/YYYY-MM-DD.md)
- **Closed**: (git SHA or vX.Y.Z when done)

## Description
What's needed and why.

## Acceptance Criteria
- [ ] criterion 1
- [ ] criterion 2
```
